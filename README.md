# منافسه ۲ — نسخهٔ آزمایشی (Sandbox) 🌙

> نسخهٔ **مستقل و کامل** پلتفرم «منافسه» برای آزمایش ایده‌ها و تغییرات بزرگ.
> هر چیزی اینجا خراب یا شکست بخورد، به **منافسهٔ اصلی (monafaseh.vodda.ir) هیچ آسیبی نمی‌زند** — دو سیستم کاملاً جدایند.

**لایسنس/مالک:** Mhabib70 · ریپوی اصلی: Vodda-ir/VoddaProject · سایت اصلی: [monafaseh.vodda.ir](https://monafaseh.vodda.ir)

---

## ✨ قابلیت‌ها (تمام امکانات منافسه)

- 🎙 **محافل زندهٔ تلاوت** — نوبت‌دهی خودکار بین حاضران، نمایش همزمان متن قرآن، صدا و تصویر (WebRTC/Jitsi)
- ⚔️ **چالش رقابت آنلاین** — رقابت ۱ به ۱ بین قاریان
- 🏅 **احراز قاری با تیک‌های سطح‌بندی** — برنزی (استانی) / نقره‌ای (کشوری) / طلایی (بین‌المللی)
- 👤 **پروفایل اینستاگرامی هر قاری** — گالری تصاویر (فشرده‌سازی خودکار)، شبکه‌های اجتماعی، مدارج، آمار
- 💼 **جلسات خصوصی پولی** — قاری قیمت می‌گذارد، دانشجو با امتیاز رزرو می‌کند، تسویه بانکی
- 💳 **خرید امتیاز** — درگاه سامان کیش (SEP شاپرک، توکن‌محور) + حمایت مالی
- 💬 **تالار گفتگو** با پیام صوتی
- 📰 **فید اجتماعی** + بلاگ
- 📱 **PWA** — نصب روی گوشی با لوگوی اختصاصی + تم روشن/تاریک
- 🛡 پنل ادمین — احراز قاریان، پرداخت‌ها، تسویه

## 🚀 راه‌اندازی

```bash
npm install
npx prisma generate
npx prisma db push
cp .env.example .env   # و مقادیر را تنظیم کنید
npm run dev
```

سپس `http://localhost:3000`

## 🗂 ساختار

```
src/app/          صفحات و API (App Router)
src/components/   کامپوننت‌های UI (نورکرافت)
src/lib/payment/  درگاه سامان کیش (token → callback → verify)
prisma/           اسکیمای دیتابیس (SQLite)
public/icons/     آیکون‌های PWA (نسخه v2)
```

## 🧪 نحوهٔ آزمایش

- این ریپو کاملاً مستقل است: هر تغییری را اینجا کامیت کنید، تست کنید.
- اگر آزمایش موفق بود، تغییرات را به اطلاع منافسهٔ اصلی برسانید تا ادغام شود.
- هرگز فایل‌های `.env` واقعی، `db/` و `public/uploads/` کامیت نشوند (gitignore آماده است).
